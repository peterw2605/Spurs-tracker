Poker Dice

Tap a cell to score it.

Who's playing?

    Each player fills every row once per column — three passes over the same card. Serve a combination in one throw and it is worth five points more.

    Scoring
    • 9s 1 point per die, 10s 2, jacks 3, queens 4, kings 5, aces 6.
    • Straight 20, full house 30, poker 40, grande 50, shit 10.
    • Served — a combination rolled in one throw — scores 5 more: 25, 35, 45, 55, 15.
    • The three columns all score the same; each is one pass over the card.
    • Any cell can be crossed out for 0 when nothing fits.
